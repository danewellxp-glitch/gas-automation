# Sons de Notificação

## notification.mp3
Som principal de notificação de novos pedidos.

### Como adicionar um som real:
1. Baixe de: https://notificationsounds.com/
2. Ou use: https://mixkit.co/free-sound-effects/notification/
3. Ou gere com: https://sfxr.me/
4. Salve como `notification.mp3` nesta pasta

### Por enquanto:
Um arquivo placeholder foi criado. O sistema funciona sem som,
mas é recomendado adicionar um som real para melhor UX.

### Requisitos do som:
- Formato: MP3
- Duração: 0.5-1.5 segundos
- Volume: Moderado
- Tom: Agradável (campainha suave ou "ding")
