   - Rota de login pública
   - Fallback para login em rotas desconhecidas


## 📊 FLUXO DE AUTENTICAÇÃO

1. Usuário acessa http://localhost:3001
2. App verifica se tem token em localStorage
3. Se NÃO tem: Redireciona para /login
4. Se tem: Carrega aplicação normalmente

5. Usuário preenche email e senha
6. Frontend faz POST para /api/auth/login
7. Backend retorna JWT token
8. Frontend salva em localStorage
9. App redireciona para dashboard
10. Requisições futuras incluem header: Authorization: Bearer TOKEN

## 🐛 TROUBLESHOOTING

Se login não funciona:
1. Verificar se backend está rodando: curl http://localhost:8000/docs
2. Testar endpoint manualmente:
   curl -X POST http://localhost:8000/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@gasautomation.local","password":"Admin@123456"}'
3. Verificar console (F12) para erros JavaScript

Se conversas não aparecem:
1. Enviar mensagem de teste (veja TESTE_FINAL_COMPLETO.txt)
2. Verificar se conversa foi criada em BD:
   docker-compose exec postgres psql -U gas_user -d gas_db \
     -c "SELECT * FROM event_log WHERE event_type='message_received' LIMIT 5;"
3. Se não há eventos, webhook não foi processado
