Objetivo: Transformar um fluxo de 8+ interações em um fluxo inteligente de 3-4 passos, onde o bot entende a intenção do cliente na primeira mensagem e pula etapas desnecessárias.

1. Correção de Botões Duplicados
Bug fix — Interface limpa para o cliente
CORRIGIDO ✅

O WhatsApp exibia as opções de operação (Troca/Comprar/Retira) duas vezes: no corpo do texto e nos botões interativos. Isso causava confusão visual para o cliente.

❌ Antes (duplicado)
🤖 Bot
✅ Botijão P13 selecionado!
💰 Valor: R$ 110,00

Como deseja?

1. 🔄 Troca (entrega vazio) - R$ 110,00
2. 🆕 Comprar vasilhame - R$ 160,00
3. 🏪 Retira na loja - R$ 110,00

[+ 3 botões iguais abaixo]
✅ Depois (limpo)
🤖 Bot
✅ Botijão P13 selecionado!
💰 Valor: R$ 110,00

Como deseja?
🔄 Troca - R$ 110,00 🆕 Comprar - R$ 160,00 🏪 Retira - R$ 110,00
Impacto: Interface limpa e profissional. Botões agora incluem o preço de cada operação, facilitando a decisão rápida do cliente.
🧠
2. Detecção Inteligente de Intenção (NLU)
O bot agora entende linguagem natural na primeira mensagem
IMPLEMENTADO ✅

O sistema _parse_intent() analisa a primeira mensagem do cliente usando expressões regulares e detecção de palavras-chave, extraindo automaticamente:

📦
Produto

P13, P20, P45
gás, botijão, 13kg

🔄
Operação

Troca, Comprar
Retira, Buscar

🔢
Quantidade

2x, 3 botijões
1 unidade

Exemplos de Frases Reconhecidas

Frase do Cliente Detecção Ação do Bot
"quero trocar meu p13" P13 Troca → Pede endereço direto
"preciso de gás" P13 (default) → Pede tipo de operação
"quero comprar botijão de 45" P45 Compra → Pede endereço direto
"manda um gas pra mim" P13 Troca → Pede endereço direto
"oi" / "olá" / "bom dia" Nenhuma → Fluxo normal (PF/PJ)
