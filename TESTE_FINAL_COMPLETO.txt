## ❌ PROBLEMAS POSSÍVEIS

### Problema 1: Página de login não aparece
- Solução: Limpar cache do navegador (Ctrl+F5)
- Solução 2: Verificar console (F12) para erros

### Problema 2: Erro ao fazer login
- Solução: Verificar credenciais
- Solução 2: Verificar logs do backend: docker-compose logs backend

### Problema 3: WebSocket erro no console
Exemplo: "Error during WebSocket handshake"
- Solução: Verificar se backend está respondendo
- Comando: curl http://localhost:8000/docs

### Problema 4: Conversas não aparecem
- Verifique se endpoint /chats está funcionando:
  curl -H "Authorization: Bearer TOKEN" http://localhost:8000/api/chats
- Substitua TOKEN pelo token obtido no login

### Problema 5: Mensagem aparece mas não em tempo real
- Recarregue a página (F5)
- Se aparecer: Backend está OK, frontend precisa de ajuste
- Se não aparecer: Webhook não foi processado
