## 🎯 Componentes Implementados

### 1. FlowEngineV2 (Orquestrador Principal)
**Arquivo:** `backend/app/core/flow_engine_v2.py`

**Responsabilidades:**
- ✅ Gerenciar ciclo de vida das conversas
- ✅ Rotear mensagens para handlers apropriados
- ✅ Integrar com NLU Engine
- ✅ Gerenciar contextos (Customer, Conversation, Order)
- ✅ Coletar métricas
- ✅ Implementar fast-track

**Método Principal:**
```python
async def process_message(
    phone: str,
    message: str,
    trace_id: Optional[str] = None
) -> List[Dict]:
```

**Fluxo de Processamento:**
1. Carregar ou criar contextos
2. Detectar intenção e extrair entidades (NLU)
3. Verificar atalhos (fast-track)
4. Obter handler do estado atual
5. Processar mensagem com handler
6. Atualizar contextos
7. Coletar métricas
8. Retornar respostas

### 2. ContextManager
**Arquivo:** `backend/app/core/context_manager.py`

**Responsabilidades:**
- ✅ Gerenciar ConversationContext (Redis)
- ✅ Gerenciar CustomerContext (PostgreSQL + Cache)
- ✅ Gerenciar OrderContext (Redis)
- ✅ Serialização/Deserialização
- ✅ TTL e expiração

**Métodos Principais:**
```python
# Conversation Context
async def get_conversation_context(phone: str) -> Optional[ConversationContext]
async def save_conversation_context(phone: str, context: ConversationContext) -> bool

# Customer Context
async def get_customer_context(phone: str) -> Optional[CustomerContext]
async def save_customer_context(phone: str, context: CustomerContext) -> bool

# Order Context
async def get_order_context(phone: str) -> Optional[OrderContext]
async def save_order_context(phone: str, context: OrderContext) -> bool
```

**Estratégia de Cache:**
- **ConversationContext**: Redis (TTL: 30 min)
- **CustomerContext**: PostgreSQL + Redis (TTL: 1 hora)
- **OrderContext**: Redis (TTL: 1 hora)

## 🔧 Funcionalidades Implementadas

### ✅ Ciclo de Vida da Conversa
1. **Inicialização**
   - Criar ou carregar contextos
   - Identificar cliente novo/retornante
   - Verificar pedidos abandonados

2. **Processamento**
   - Detectar intenção (NLU)
   - Extrair entidades
   - Verificar fast-track
   - Executar handler apropriado

3. **Transição**
   - Atualizar estado
   - Salvar histórico
   - Atualizar contextos

4. **Finalização**
   - Salvar contextos
   - Coletar métricas
   - Retornar respostas

### ✅ Gerenciamento de Contextos
- **Conversation**: Estado atual, histórico, dados coletados
- **Customer**: Dados pessoais, endereços, preferências
- **Order**: Itens, total, endereço, pagamento

### ✅ Integração NLU
- Detecção de intenção (3 camadas)
- Extração de entidades
- Confiança e métricas

### ✅ Fast-Track
- Repetir último pedido
- Pedido completo em uma mensagem
- Pular estados desnecessários

### ✅ Métricas e Monitoramento
- 15+ métricas Prometheus
- Rastreamento de performance
- KPIs em tempo real

### ✅ Rollout Gradual
- Feature flag global
- Rollout percentual
- Hash baseado em telefone

## 🎯 Exemplo de Uso

### Inicialização
```python
from app.core.flow_engine_factory import get_flow_engine_v2, is_v2_enabled

# Verificar se V2 está habilitado
if is_v2_enabled(phone):
    # Obter engine
    engine = await get_flow_engine_v2()
    
    # Processar mensagem
    responses = await engine.process_message(
        phone="5511999999999",
        message="quero 2 P13 troca"
    )
    
    # Enviar respostas
    for response in responses:
        await send_whatsapp_message(phone, response)
```

### Monitoramento
```python
from app.core.metrics_collector import get_metrics_collector

# Obter métricas
metrics = get_metrics_collector()

metrics.increment_message_count(status="success")
metrics.record_processing_time(time_ms=150.5)

    from_state="greeting_initial",
```
