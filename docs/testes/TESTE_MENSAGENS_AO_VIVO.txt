   - Com o conteúdo "Olá! Esta é uma mensagem de teste"

## 🔍 DIAGNÓSTICO SE NÃO FUNCIONAR:

### Opção A: Verificar logs do backend
   
   docker-compose logs backend -f
   
   Procure por:
   - "WebSocket conectado" = conexão estabelecida ✅
   - "WebSocket emitido para" = mensagem enviada ✅
   - "Processando mensagem" = webhook recebido ✅

### Opção B: Testar WebSocket puro
   
   Abra em novo navegador:
   http://localhost:8888/test_websocket.html
   
   Isto NÃO usa autenticação e deve mostrar:
   - "✅ WebSocket aberto!"
   - "📨 Mensagem recebida: {"type":"new_message"...}"

### Opção C: Verificar erro no console (F12)
   
   Tipos de erro comuns:
   
   1) "Error during WebSocket handshake: ..."
      = Backend não está respondendo
      Solução: docker-compose restart backend
      
   2) "HTTP 403 Forbidden"
      = Token JWT inválido/expirado
      Solução: Fazer logout e login novamente
      
   3) Nenhum erro, mas não recebe mensagem
      = WebSocket conectado mas broadcast não está funcionando
      Solução: Ver logs do backend com grep "broadcast"

### Opção D: Testar endpoint de status
   
   curl http://localhost:8000/docs
   
   Deve retornar 200. Se retornar 502/503 = backend down

   Console (F12):

   (mas nada mais aparece)
   
   Solução:
   - Mensagem chegou no backend? Ver logs
   - Backend processou? Procurar "WebSocket emitido"
   - Frontend ouve? Adicionar console.log no onmessage
